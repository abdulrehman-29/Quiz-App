# 🎯 Quiz App

A simple and easy-to-use Quiz Application built with pure **HTML, CSS, JavaScript**, and **LocalStorage**.

---

## ✨ Features

* 🔐 **Login & Signup System:** User details are saved locally in the browser using `LocalStorage`.
* ⏱️ **20-Second Timer:** Each question has a 20-second timer. If time finishes, it automatically goes to the next question.
* 🚫 **Button Lock:** The "Next" button stays disabled until an option is selected.
* 📊 **Result Page:** Shows your total score after finishing the quiz.

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla)**
* **LocalStorage API**
